Kelivo MCP client behavior
=========================

The remote MCP configuration and connection workflow adapts behavior from
Chevey339/kelivo (https://github.com/Chevey339/kelivo), licensed under GNU
Affero General Public License version 3. This Lumi implementation supports
remote Streamable HTTP for iOS; it does not include Kelivo's Flutter UI, OAuth
client, or desktop STDIO transport. The license is included in
`LICENSES/Kelivo-AGPL-3.0.txt`.

Port and integration changes: 2026-10-11.
